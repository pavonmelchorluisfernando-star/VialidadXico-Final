# 🚨 Sistema Vialidad Xico - Veracruz

Sistema de Reporte de Operativo de Motos para el Ayuntamiento de Xico, Veracruz.
Desarrollado para tabletas Android, para registrar infracciones en campo de forma rápida y profesional.

## ✨ ¿Qué hace?

- Registro de placas de motocicletas
- Falta de Casco
- Posible Exceso de Velocidad
- Exceso de Pasajeros
- Sentido Contrario
- Observaciones
- Exportación a Excel profesional
- Funciona sin internet en la tablet

## 📱 ¿Cómo se usa?

1. Abre la app, toca el logo para entrar
2. Llena Fecha, Num. Placa y marca las faltas
3. Dale Guardar
4. Al final del operativo, exporta a Excel

## 🛠️ Tecnologías

- Kotlin
- Android Studio
- WebView + HTML / JavaScript
- Excel Export

## 📦 Instalación

1. Descarga el APK
2. Instálalo en tu tablet Huawei / Android
3. Permite "Instalar de origen desconocido" si te lo pide
